Atlas Careers

Atlas Careers is Yinan Feng’s personal, local-first job-search and application management tool. It discovers public employer postings, records source evidence, prepares resumes from verified facts, and tracks actual applications and recruiting correspondence.

How Gmail is used

The desktop installation requests Gmail read-only access through Google OAuth. It checks recruiting-related messages, retains selected headers and snippets locally, and links a message to an application only when application and sender evidence support the match. Gmail is checked periodically while the Mac is awake and online.

Where it runs

The private workspace, applicant facts, application records and imported email metadata run on the owner’s Mac. This public website explains the software and hosts professional portfolio content.
