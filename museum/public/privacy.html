Privacy notice

This notice describes the personal Atlas Careers installation operated by Yinan Feng. The public website contains professional project information and a resume.

Google access

The app requests the OAuth scope https://www.googleapis.com/auth/gmail.readonly. Google describes this as permission to view email messages and settings. Atlas uses it to find recruiting correspondence, read message metadata and snippets, and maintain an incremental synchronization cursor.

Information stored

The app stores selected message identifiers, thread identifiers, sender headers, subjects, snippets, dates, classifications and original Gmail links in a local SQLite database. The initial search covers the previous 180 days using recruiting keywords. Message labels and matching confidence are review aids. Application outcomes require supporting evidence.

Storage and sharing

OAuth client configuration and tokens are stored in macOS Keychain. Applicant facts, imported email records and generated documents stay in the local installation. The app uses Google APIs to obtain account and message data. Its Gmail authorization is read-only. Third-party AI services receive no Gmail data through this implementation. The public static website contains professional content and licensed frontend assets. The hosting provider processes ordinary website requests under its own policies.

Retention and controls

Controls provides an export and deletion of imported local email records. Deletion pauses mail synchronization. Local database backups follow a 14-day retention policy. The user can disconnect Gmail in Atlas or revoke access through Google Account connections. Disconnecting revokes the token and preserves previously imported records for separate review or deletion. The documented full local-data deletion procedure includes retained backups.

Limited use

Atlas Careers’ use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google data is used for the user-requested recruiting workflow. It is not sold, used for advertising, or used to train a generalized AI model.
