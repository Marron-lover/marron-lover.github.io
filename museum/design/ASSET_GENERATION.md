# Original sculpture asset set

Created with Codex’s built-in image generation tool, one generation per subject. The selected original RGBA PNGs are saved locally under `museum/art-source/`; transparent WebP production assets are in `museum/public/assets/`. Conversion preserves alpha. The original artwork files are 1254 × 1254 pixels. The private reference screenshots and original PNGs stay outside the published build.

## Prompt set — normalized generation brief

Common art direction: a whimsical but sophisticated sculptural 3D collectible, glossy soft polymer with physically convincing material, rounded sculptural geometry, soft studio light from the upper left, three-quarter view, a single complete object isolated on a genuinely transparent background. Cohesive high-end digital exhibition art direction. Keep lettering, brand marks, borders and watermarks out of the artwork.
